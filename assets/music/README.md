# Nhạc của Chie

Đặt tệp MP3, OGG, WAV hoặc định dạng âm thanh mà trình duyệt hỗ trợ vào đây.
Chỉ dùng bản thu bạn sở hữu hoặc được phép công khai. Không có nhạc mẫu kèm theo.

Tạo thư mục `covers/` nếu muốn thêm ảnh bìa WebP, JPG hoặc PNG. Trong `config.js`,
thêm từng bài vào `playlist` với `title`, `artist`, `src` và `cover` (không bắt buộc).
Ví dụ đường dẫn: `assets/music/my-song.mp3`, `assets/music/covers/my-cover.webp`.
Tên tệp và chữ hoa/thường phải khớp chính xác. Tệp trên website là công khai.
Xem README ở gốc dự án để biết các bước đầy đủ.
